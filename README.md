# DIDAR GitHub Pages website

A simple static website for DIDAR.

## Files
- `index.html` — website content
- `styles.css` — visual design
- `.nojekyll` — tells GitHub Pages to serve the site as a plain static site

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `didar`.
2. Upload all files from this folder to the repository.
3. Open the repository **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
6. Save.

GitHub will show the public site URL after deployment.

## Before publishing

Edit `index.html` and replace:
- `YOUR-EMAIL@example.com`
- `Add Instagram link`

You can also change project descriptions and service categories directly in `index.html`.
